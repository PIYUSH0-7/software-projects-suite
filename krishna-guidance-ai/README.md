# 🦚 Krishna’s Guidance — Your Divine Mentor

A modern, interactive web application inspired by the timeless wisdom of **Shri Krishna**, designed to provide guidance, clarity, and motivation for daily life through a clean, distraction-free digital experience.

> _“Whenever dharma declines and adharma rises, I manifest myself.”_ — Bhagavad Gita

---

## ✨ Features

- 📜 Divine guidance inspired by **Bhagavad Gita**
- 🧠 Mentor-style responses for life, discipline, and purpose
- ⚡ Fast, lightweight UI built with **Vite + React**
- 🎨 Clean, minimal, spiritually calm design
- 🛡️ Environment-based configuration support
- 📱 Fully responsive (mobile & desktop)

---

## 🛠️ Tech Stack

- **Frontend:** React + TypeScript
- **Bundler:** Vite
- **Styling:** CSS / modern component-based styling
- **Configuration:** `.env` support
- **Version Control:** Git & GitHub
